# 点兵三国 · 骑砍大师制作

骑马与砍杀式的**竖屏战略经营**小游戏，三国背景、中国全图。以微信小游戏工程交付，同一套代码兼容抖音小游戏与浏览器预览。

全部美术（地形、城池、单位、UI）都由 Canvas 代码逐像素生成，**没有任何图片资源**，整个工程约 210 KB，打开即玩。

仓库：https://github.com/duwutao/wxgame_qimayukanshajy

```
洛阳溃兵 → 陈留募兵 → 官渡烧粮 → 下邳围城 → 赤壁截杀 → 夷陵连营 → 定稿之战
```

## 一、玩法

**大地图**
40×48 格的中国全图，12 个区域（塞北草原 / 幽燕 / 并州山地 / 冀州平原 / 凉州戈壁 / 关中 / 中原 / 徐州 / 益州 / 荆州 / 江东 / 交州），每个区域有自己的配色与风物。55 座城、关、村、贼巢，黄河长江淮河与九条山脉用地形折线绘制。魏、蜀、吴、袁、吕布、刘表、张鲁、鲜卑、马腾、韩遂十方势力。

点地图上的城池即可行军；到达后进入城池界面。拖动地图可看其它地方，顶栏可调 1x / 2x / 3x 倍速。

**城池**
进去先看自己的家底：金、粮（含日耗）、兵（含上限）、声望、天机简、士气。然后是大按钮选项：

- 招兵：按城定价，声望不够的兵种锁着
- 市场：粮草 / 军械 两页。粮草买卖，军械换兵刃、甲胄、坐骑
- 酒馆：接活、交粮、打听传闻
- 领主府：看关系、宣誓效忠、宣战、攻城
- 村庄可劫掠（抢粮抢钱，掉声望，得罪其主）

**围城**
城与关隘要先扎营围 1—2 天；围城时辰走满后自动暂停，弹出「进攻城池 / 拔营离开」选择，选完世界才继续走。

**战斗**
遭遇战、追兵、领主战、攻城战、战役战五类。开战前选战术（全军冲锋 / 结阵固守 / 骑兵包抄 / 弓弩先射），战中每 0.6 秒自动推一轮，战报逐条刷。

**天机简**
全游戏最贵的东西。每支天机简可以在战中改一次战局：

| 天机简 | 效果 |
|---|---|
| 南风起 | 本方攻势 +90%，火攻额外 +50% |
| 风止 | 双方攻击 -70%，持续 3 回合 |
| 名册 | 战后阵亡我方回归 70% |

不再反噬天下关系；剧情只给五支，其余可在天机简商店看广告领取（每日上限十支）。

**势力与领主**
21 位三国人物（曹操、夏侯惇、张辽、刘备、关羽、张飞、孙权、周瑜、太史慈、袁绍、颜良、吕布、高顺、刘表、蔡瑁、刘璋、张任、轲比能、马腾、马超、皇甫嵩）。关系低于 -25 即开战，敌对领主在视野内会盯上你、追着你打；你攻城、劫村、宣战，都会把关系往下拉。

**战役链**
十二章主线：序章洛阳溃兵 → 陈留募兵 → 濮阳粮车 → 陈留整军 → 官渡乌巢 → 下邳白门楼 → 白门楼降卒 → 寿春粮市 → 夏口借船 → 赤壁 → 夷陵 → 终幕定稿之战。

主线走完后不再强制结局，玩家可以继续攻城、封地、外交，直到把所有城都握在手里。第一次统一会触发三十天大旱、天下皆反、流亡边陲小城；只有从队伍里出去的旧部还愿意跟随。第二次统一后进入尾声，可选择留在这片大陆继续经营，或离开回到标题。

**结局**
主线老结局保留为旧档结算；新流程是：统一 → 大旱流亡 → 带旧部再统一 → 国泰民安 → 留下或离开。

游戏内「玩法」页分五个标签页：基础 / 战役 / 势力 / 兵种 / 结局，随时可查。

## 二、运行

**微信小游戏**
用微信开发者工具导入本目录（`compileType: game`）。`project.config.json` 里的 `appid` 现在是 `touristappid` 占位，真机预览或上传前必须换成自己的小游戏 AppID。

**浏览器预览**
```bash
node tools/bundle.js     # 把 js/ 打成 web/game.bundle.js
node tools/serve.js      # 打开 http://localhost:8901/
```
改了 `js/` 下任何文件都要重新 bundle，否则浏览器跑的还是旧代码。

**抖音小游戏**
`js/render/platform.js` 会优先探测 `tt`，无需改代码。把 `project.tt.json` 改名成 `project.config.json` 并填抖音小游戏 AppID。

## 四、关键数值

- 设计分辨率宽 750；地图格 64px；顶栏 132 / 底栏 176
- 行军：平原 2.0 小时/格，道路 1.3，林地 2.9，沼泽 4.3；山地与海不可通行
- 部队上限 `max(30, 20 + 声望×0.35)`
- 口粮：民兵 1 / 骑手 3 每人每天；断粮会跑兵
- 存档 key `bw_save_v3`，版本号不符直接拒绝旧档
